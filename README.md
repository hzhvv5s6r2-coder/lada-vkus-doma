# ЛАДА — вкус дома

Автономный адаптивный сайт русской домашней кухни. Откройте `index.html` в современном браузере — сборка не нужна.

## Реализовано
- Главная editorial-страница, каталог 24 рецептов, поиск по названиям и ингредиентам, фильтр категорий и сортировка.
- Индивидуальные страницы рецептов с ингредиентами, пересчётом порций, шагами, заметками, печатью и режимом приготовления.
- Избранное, список покупок с сохранением в localStorage, подбор блюд по ингредиентам и времени.
- Региональный раздел, журнал, страница о проекте и контакты.
- Адаптивная мобильная навигация, семантические элементы, reduced-motion, базовые SEO/OG метаданные.

## Ограничения автономной версии
- Рецепты и состояние хранятся в браузере; аккаунтов, облачной синхронизации и серверной базы данных нет.
- Форма обратной связи открывает почтовое приложение, а не отправляет сообщение на сервер.
- Для фотографий и веб-шрифтов требуется подключение к интернету.
- Рецептурные шаги — стартовые редакционные инструкции; перед публикацией как кулинарный справочник стоит провести редакционную и кулинарную проверку.
- Для production-развёртывания рекомендуется перенести проект в Next.js/TypeScript, подключить базу данных, настроить реальные canonical URL, sitemap, robots.txt и валидировать Recipe structured data.
